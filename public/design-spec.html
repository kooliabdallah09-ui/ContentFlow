09 — Design principles
Warm, not sterile
Off-white backgrounds (#FAFAF8 not #F9F9F9). Warm ink (#1A1A17 not #000). Feels like paper, not a Google product.
Serif + sans pairing
Headlines in Instrument Serif italic. Body/UI in Geist. Eyebrows in Geist Mono. Never mix more than these three.
No blue accent
Primary CTA = ink (near-black). No blue, purple, or teal accents. The brand color IS the content color.
Subtle structure
Borders at 1px, shadows minimal. Content hierarchy from typography and spacing — not heavy borders or colors.
Dark mode = true dark
#111110 background, warm dark surfaces. Buttons in dark mode use --ink (the off-white #EDEAE2) as background.
Inline styles (no Tailwind)
All component styles use CSS custom properties inline. No Tailwind, no CSS modules. One globals.css with tokens.
